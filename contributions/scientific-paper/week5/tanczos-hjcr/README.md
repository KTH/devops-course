## Description

We will present *The Seven Sins: Security Smells in Infrastructure as Code Scripts* by Akond Rahman, Chris Parnin, and Laurie Williams, published at the IEEE/ACM International Conference on Software Engineering (ICSE) 2019. The paper investigates security weaknesses in Infrastructure as Code by identifying seven recurring security smells and developing SLIC, a static analysis tool for detecting them. The authors analyse 15232 IaC scripts from 293 open-source repositories and investigate the frequency, lifetime, and developer perception of these security smells.

**Relevance**

The paper is directly related to DevOps and the Infrastructure as Code topic, as it demonstrates important software vulnerabilities that can be introduced in IaC scripts such as hard-coded secrets, insecure HTTP usage, and weak cryptographics algorithms. It proposes a static analysis tool to mitigate these issues. This also connects to broader DevOps practices including automation and continuous security.
