## Description

We want to present the paper **Asleep at the Keyboard? Assessing the Security of GitHub Copilot’s Code Contributions** where the authors systematically investigate the security risks in source code generated by GitHub Copilot. By prompting Copilot with scenarios targeting high risk weaknesses, based on the MITRE “Top 25” Common Weakness Enumeration (CWE) list, they analyze over 1,600 generated programs for vulnerabilities. The study finds that approximately 40% of Copilot’s code suggestions are insecure, with particular weaknesses surfacing in multiple programming languages and across diverse domains.

This paper can be found here: [link to paper](https://dl.acm.org/doi/full/10.1145/3610721).

**Relevance**

The security of AI generated code is an emerging and critical concern in software engineering, especially as tools like GitHub Copilot become mainstream. This paper’s analysis is highly relevant to the course topic of automated code generation and software security, providing practical insights into integrating security checks within AI powered development pipelines. The findings directly impact how automated tools should be evaluated, adopted, and governed in modern software projects and CI/CD practices.
