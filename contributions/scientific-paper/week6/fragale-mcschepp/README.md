## Description

We propose to present the paper Package Hallucinations as Phantoms in Open-source Software Supply Chains: An Empirical Security Analysis by Zhe Huang et al. (https://doi.org/10.1145/3830237) published on the ACM Transactions on Software Engineering and Methodology 2026.

LLMs can recommend software packages that do not exist. This paper studies the next question: can those hallucinated package names can be exploited as a practical software supply-chain attack.

The authors investigate this through an experiment in the npm ecosystem where they registered hallucinated package names and measured how often, and by whom, these packages were installed.

We will explain the paper’s three-phase attack model and discuss a small set of key empirical findings showing that the threat is very relevant, especially considering the short time window in which many interactions occur.

We will present then NymGuard, the defense system proposed by the authors. NymGuard combines package hallucination detection, preemptive registration of safe placeholder packages, and real-time warning and monitoring. We will explain how these components interact and how they provide a defense for software supply-chain security.

We will also critically discuss the limitations and assumptions of the approach and in general when this type of defense is useful and when it is not.

**Relevance**

The paper is directly relevant to DevOps and DevSecOps because modern delivery pipelines rely on automated dependency management and public package registries such as npm. 
A malicious dependency introduced during development can propagate and eventually reach also production environments.

The work is also relevant to AI-assisted software development, where LLM-based coding tools increasingly influence dependency selection. This creates a new trust boundary: developers may rely on package recommendations generated by AI without independently verifying them.
