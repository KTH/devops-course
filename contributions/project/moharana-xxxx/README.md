## Description

This project implements an API-first REST service called **OpenWeather API** using the OpenAPI Specification. The repository will contain the API definition, source code, automated tests, and GitHub Actions workflows.

Using **GitHub** and **GitHub Actions**, the project will establish a Continuous Integration (CI) pipeline that automatically validates the OpenAPI specification, performs linting, executes unit tests, runs security checks, and builds the application for every push and pull request.

To ensure quality and reliability, the project will use **Spectral** for OpenAPI linting, **Jest** for automated testing, **CodeQL** for security analysis, and **Dependabot** for dependency management. The use of AI-assisted tools such as GitHub Copilot and ChatGPT will also be documented as part of the development process.

### Relevance

REST APIs are a core component of modern software systems, making API quality and reliability essential. This project demonstrates how Continuous Integration (CI) can automate API validation, linting, testing, security scanning, and build verification using an API-first approach with OpenAPI. By providing fast feedback and early defect detection, the project reflects industry best practices and offers practical experience with tools commonly used in modern DevOps and cloud-native development environments.
