## Description

In this tutorial we want you to learn how to use **MLflow** to track machine learning experiments, log hyperparameters and performance metrics, and manage trained models. We will use a simple dataset, train multiple models with different configurations, then compare their results and demonstrate how to reload a saved model for reuse.  

**Intended Learning Outcomes**  
- Train a simple model  
- Log parameters, metrics, and models with MLflow  
- Compare experiments  

**Outline**  
1. Introduction  
2. Setup environment
3. Load dataset  
4. Build a simple ML pipeline 
5. Track experiments with MLflow  
6. Run multiple experiments  
7. Compare results
8. Load and reuse a saved model  
9. Summary & key takeaways  

**Relevance**

In MLOps, being able to reproduce experiments (with the same conditions) and look back on logs is critical. You will often run many experiments, and without proper tracking the result easily get lost.
