## Description
This demonstration will show how property-based testing can be used to both lower time
and increase precision in testing, as well as automate the systemic test writing. We will
specifically show what property-based testing is and how it works, and potentially show
some Haskell specific implementations using the Quickcheck library.

**Relevance**
Property-based testing is used extensively both in CI and to automate the task of
writing tests, with a more declarative approach.

Haskell is of specific interest, since most other implementations of property-based testing can
be tracked back to Haskell, and the QuickCheck library.
