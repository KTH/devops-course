## Description

For this demo we want to show how to set up a SonarQube server using Github Actions in order to automatically detect potential hardcoded and block secrets leaking to production. Using a simple repository we will show how to set-up SonarQube and what happens if SonarQube detects a leak.

**Relevance**

By integrating SonarQube in Github Actions, DevOps teams can automatically scan every commit for leaked secrets. This ensures security checks happen early in the CI/CD pipeline, blocking leaks before they reach production. It reduces human error and provides developers with instant feedback when risky code is introduced and the releases are faster, and safer.
