## Description
[Keep](https://github.com/keephq/keep) is an open source AIOps alert management platform. It can use various LLM backends, including OpenAI, DeepSeek and Grok. In our demo we will demonstrate how to deploy it for alert management in you project.

**Relevance**

Alerts and notifications are vital for observability in DevOps work. However, they must be filtered to avoid alert fatigue. Keep can be configured to provide relevant alerts for DevOps.
