# Assignment Proposal

## Title

Stop Rebuilding the Wheel: Accelerating Monorepos with Turborepo's Remote Cache

## Names and KTH ID

- Jonatan Stagge (jstagge@kth.se)

## Description

The presentation will explore how Turborepo, a high-performance build system for monorepos, leverages Remote Caching to drastically reduce redundant work across both CI pipelines and local developer environments.

**Relevance**

By optimizing CI and local build processes, these tools drastically reduces wasted computational effort and developer waiting times.
Efficient build times make CI enjoyable, not a burden, encouraging better practices.
