## Description

We would like to share **_Trivy_**, an open-source vulnerability scanner that helps integrate security into DevOps workflows. The presentation will show how Trivy works, like detecting vulnerabilities in Docker images by matching against vulnerability databases, and a practical use case where Trivy is added to a CI/CD pipeline to prevent deploying insecure applications. 

**Relevance**

Security maybe the weakest link in DevOps pipelines, where teams prioritize speed over safety. By integrating Trivy, developers can automatically catch vulnerabilities early, ensuring safer deployments without slowing down delivery. This topic is relevant since it demonstrates a clear use case (container scanning in CI/CD), provides technical insights (how Trivy identifies vulnerabilities), and highlights the growing importance of DevSecOps in modern software development.
