## Description

We will compare DevOps and MLOps practices and highlight why deploying AI/ML models is more complex than deploying “traditional” software. Since DevOps focuses on automating the delivery of code through CI/CD,  we will highlight how MLOps builds on these practices by adding data validation, model training, evaluation, and monitoring. We also plan on mentioning the benefits and disadvantages of both MLOps and DevOps. 


**Relevance**

MLOps is directly related to DevOps because it applies the same automation and pipeline principles to different AI systems. Understanding MLOps helps show how DevOps practices must further evolve and develop to handle not just code,  but also data, and models.
