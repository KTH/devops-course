## Description

We plan to make a presentation on the Model Context Protocol (MCP), what it is and why it was made. We will exemplify it by explaining how to use a MCP Server to create and utilize a LLM-workflow binding.

**Relevance**

We want to be able to apply state-of-the-art language models in our DevOps workflows, but the workflow and the LLM need a way to communicate, and that is where MCP comes in!
