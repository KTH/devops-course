## Description

We will present MLOps as an extension of DevOps that focuses on the specific challenges of running machine learning systems in production. We compare the DevOps and MLOps lifecycles, explain ML-specific needs like data validation, drift detection, continuous evaluation, model and data versioning, and monitoring, and discuss both the benefits and the downsides.


**Relevance**

DevOps is about reliable delivery of code through CI/CD. MLOps builds on these same ideas but adds extra steps to handle data and models, which is key for keeping AI systems trustworthy in production. By applying DevOps practices to machine learning workflows, MLOps ensures that models remain accurate, reliable, and maintainable in production environments
