## Description

Traditional DevSecOps practices promote a shift-left security culture, aiming to secure software as early as possible in the development process. Security by obscurity is often dismissed a non viable solution. At the same time it is a widely used practise amongst malware developers.

Taking inspiration from adversarial techniques, obfuscation is a technique that transforms source code or binary code into a form that is still functional but much harder to interpret. When used in a defensive context, obfuscation can helpt protect secrets, intellectual property and vulnerabilities.

In this presentation, we aim to discuss what obfuscation is and discuss whether it can be used as a DevSecOps technique. Moreover, we will present a concrete example using a tool such as [Pyarmor](https://github.com/dashingsoft/pyarmor).

**Relevance**

The topic relates to DevOps and particularly DevSecOps as it presents if and how obfuscation fit in the traditional DevSecOps context, as a technique to increase the level of security in software.
